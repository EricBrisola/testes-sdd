## Summary

Implementação da tela principal de Cadastro de Movimentações (formulário de inserção) no frontend React e a respectiva rota `POST` no backend Fastify. A modelagem no Prisma utilizará `Enum` para Tipo (Entrada/Saída) e Método de Pagamento (Pix/Dinheiro/Cartão) e Chave Estrangeira (FK) para Categoria. Operações no banco usarão `$transaction` para garantir a integridade ACID.

## Technical Context

**Language/Version**: TypeScript 5+ no Node 20 (backend) e Vite (frontend)

**Primary Dependencies**: Fastify (Backend), React + Styled Components (Frontend), Prisma (ORM)

**Storage**: PostgreSQL

**Testing**: Jest e React Testing Library

**Target Platform**: Web (Foco principal na usabilidade Mobile-First)

**Project Type**: Web Application (Monorepo Backend/Frontend)

**Constraints**: Autenticação estrita (JWT HttpOnly cookies). Todas rotas protegidas. Formulário responsivo minimalista.
